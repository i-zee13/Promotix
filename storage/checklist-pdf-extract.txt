1. Sab Se Pehle: System Ka Golden Rule
Golden Rule
IP Address hamesha dashboard ka anchor rahega, lekin IP ko "ek insan" ya "ek device" mat samjho. Repeat click decision ke liye 
Device ID + Browser ID + Visitor ID + Fingerprint similarity + Session history ko correlate karo. Block owning identity ko pehle 
karo; IP exclusion baad mein eligibility gate se guzray.
Paid Advertising Protection ka sawal bot protection se different hai: "kya ye paid click advertiser ke liye repetitive, manipulated, 
automated, competitive, accidental ya invalid lag raha hai?" Bot evidence supporting signal ho sakta hai, lekin paid module ki apni 
identity aur repeat-click logic honi chahiye.
 Score-first system mat banao. Identity-first + rule-first + score-when-uncertain model banao.
 Decisive rule fire ho to 85/100 ya 100/100 ka wait mat karo.
 Same IP only = low identity confidence. Same Device + Browser + Fingerprint >=90% = very high identity confidence.
 GCLID / GBRAID / WBRAID attribution identifiers hain; physical Device ID nahi.
 Dashboard compact rakho; Advanced View forensic detail ke liye use karo.
