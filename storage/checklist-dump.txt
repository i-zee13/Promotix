===SHEET: Detection Rules
R1|Recommended Detection Rule Matrix							
R2|							
R3|Rule	Trigger	Initial Classification	Risk Points	Action	Escalation	Admin Configurable	Notes
R4|New clean visitor	First paid click, no strong risk indicators	Valid	0	Allow and record	Re-score when new signals arrive	Yes	Do not punish a normal first click.
R5|Rapid repeat	Second paid click from same IP within 2 minutes	Invalid / Suspicious	35	Record as invalid; optionally challenge	Block if threshold reached	Yes	Use campaign and click-ID context.
R6|Repeated paid clicks	Third paid click from same IP within configured window	Blocked	70	Block IP temporarily or permanently	Sync to exclusion list when eligible	Yes	Default should be configurable.
R7|No interaction	No mouse, scroll, click, or meaningful activity after minimum session time	Suspicious	20	Record signal, do not block alone	Combine with repeat or bot signals	Yes	Avoid false positives from quick readers.
R8|Repeated identical behavior	Same IP/device repeats nearly identical low-human session pattern	Invalid	30	Increase risk score	Block when combined score passes threshold	Yes	Use similarity evidence.
R9|VPN / proxy	Known anonymizer or proxy reputation	Suspicious	15	Record signal	Combine with other signals	Yes	VPN alone should not always block.
R10|Datacenter ASN	Traffic originates from hosting/datacenter network	Suspicious	25	Challenge or increase score	Block in Extreme mode if other evidence exists	Yes	Handle legitimate corporate networks carefully.
R11|Automation signals	Headless browser, impossible timing, scripted events, webdriver indicators	Invalid	50	Block or challenge	Permanent block for repeated automation	Yes	Store exact reason codes.
R12|Explicit allow list	IP exists in allow list	Allowed Override	-100	Allow	Continue logging	Yes	Highest precedence by default.
R13|Explicit block list	IP exists in block list	Blocked	100	Deny before page load	Remain blocked until expiry/removal	Yes	Second precedence after explicit allow.
R14|Google invalid match	Google reports click as invalid	Google Invalid	0	Label and reconcile	Deduplicate overlap	No	Keep separate from internal detection.
