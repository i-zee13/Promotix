Install the Clickronix tracking tag on your WordPress site.

== Description ==

Clickronix Tag injects the Clickronix tracking script into your WordPress site's `<head>` so you can monitor traffic, clicks, and threats from your Clickronix dashboard. When a visit is blocked, visitors see the Clickronix logo and message.

After installing:

1. Open **Settings → Clickronix Tag**
2. Paste your **Server URL** and keys from your Clickronix dashboard:
   - Domain key
   - Secret key
   - Authentication key
3. Save.

== Installation ==

1. In WordPress Admin, go to **Plugins → Add New → Upload Plugin**
2. Upload the ZIP file and click **Install Now**
3. Click **Activate**
4. Go to **Settings → Clickronix Tag** and paste your keys
5. Enable the tag and save
